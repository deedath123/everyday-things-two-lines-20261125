# Everyday Things, Two Lines, Longer Run

A two-line take on an everyday thing — a zipper, a row of tiny hands holding tight, tooth by tooth.

> A zipper is a row of tiny hands holding tight: pull the tab and each hand grabs the next one, closing the gap tooth by tooth.
> The holding-hands part is right — the teeth really do lock together in order — but real hands can let go and grab anyone, while each zipper tooth only ever meets the same partner, in the same line.
